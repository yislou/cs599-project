# Product Spec — Agentic RAG 智能知识库助手

> **版本**: v1.0  
> **日期**: 2026-06-07  
> **状态**: MVP (Milestone 2)

---

## 1. 产品概述

### 1.1 产品定位

Agentic RAG 智能知识库助手是一款基于 **检索增强生成 (RAG)** 与 **AI Agent** 技术的智能问答系统。用户可以上传文档构建私有知识库，系统通过 Agent 的多步推理能力自动检索、分析并生成精准回答。

### 1.2 核心价值

| 痛点 | 解决方案 |
|------|---------|
| 大量文档难以快速查找关键信息 | 语义检索代替关键词搜索 |
| 传统搜索需要人工阅读和归纳 | Agent 自动推理并总结答案 |
| 对话式问题难以单次检索解决 | 多轮对话 + 上下文记忆 |
| 答案来源不可追溯 | 每次回答附带引用来源 |

### 1.3 目标用户

- 需要快速检索企业内部文档的知识工作者
- 需要分析学术论文的研究人员
- 需要自动化信息提取的各类专业人士

## 2. 功能需求

### 2.1 MVP 功能 (v0.1)

| 功能 | 优先级 | 描述 |
|------|--------|------|
| 文档上传与索引 | P0 | 支持 PDF/TXT/MD/DOCX 格式上传，自动分块与向量化 |
| 语义检索 | P0 | 基于向量相似度的语义搜索，返回 Top-K 相关片段 |
| Agent 问答 | P0 | 支持多步骤推理的智能问答，自动调用检索工具 |
| 多轮对话 | P0 | 维护对话历史，支持追问和上下文理解 |
| 来源引用 | P0 | 答案中标注信息来源文档名称 |
| 知识库管理 | P1 | 查看已索引文档列表、删除文档、清空知识库 |
| Agent 思考过程展示 | P1 | 展示 Agent 调用的工具和中间推理步骤 |

### 2.2 后续版本功能 (v0.2+)

| 功能 | 描述 |
|------|------|
| 多格式更深度支持 | 图片 OCR、表格解析、PPT |
| MCP 协议集成 | 通过 MCP 外挂工具扩展 Agent 能力 |
| 多知识库切换 | 支持多个 Collection 独立管理 |
| 用户认证 | 多用户隔离的知识库 |
| REST API | 提供 API 接口供其他系统集成 |
| 评估体系 | 检索质量评估、答案准确性 Benchmark |

## 3. 非功能需求

| 类别 | 要求 |
|------|------|
| **安全性** | API Key 通过环境变量管理，不得硬编码；文档隔离存储 |
| **可观测性** | Agent 思考链可视，工具调用日志可查看 |
| **可扩展性** | 工具接口标准化，可新增 Agent Tools；支持切换不同 LLM |
| **性能** | 单次问答响应 < 30s（含检索+推理） |
| **兼容性** | 支持 Docker 一键部署，跨平台运行 |

## 4. 用户故事

### US1: 上传文档并提问
> 作为用户，我希望能上传一份 PDF 报告，然后直接向系统提问内容，系统能基于文档内容给我准确答案。

**验收标准：**
- 上传 PDF 后能在知识库列表中看到
- 提问后答案引用了该文档来源
- 答案与文档内容一致

### US2: 多轮追问
> 作为用户，我希望能基于上一轮的回答进行追问，系统能理解上下文。

**验收标准：**
- 追问 "刚才说的 XX 具体是什么？" 能正确理解 "XX" 指代
- 对话历史中能看到完整上下文

### US3: 知识库管理
> 作为用户，我希望能查看已上传的文档列表，并能删除不需要的文档。

**验收标准：**
- 侧边栏实时显示已索引文档
- 删除操作后立即生效
